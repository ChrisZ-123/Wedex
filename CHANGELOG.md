# Changelog

## 0.1.0 — Preview

Release tag: `wedex-v0.1.0`.

- Prepare Wedex as an independent WeChat-only project from the current Webot implementation.
- Add a Windows launcher with install/check, start, open-console, status and stop actions.
- Prepare pinned project-local Node.js and official Codex runtimes, locked npm dependencies and a current-user on-demand backend task.
- Preserve owner-only private chat, dynamic account model settings, context, roles, versioned memory, feedback, local stickers, history and backup/restore.
- Preserve native web search, vision and image creation/editing, subject to official account and channel support.
- Document account isolation, third-party provenance and the separation between earlier phone evidence and current release checks.

See [validation](docs/VALIDATION.md) for checks actually completed. This preview does not imply that every feature has been tested on every Windows or account configuration.
