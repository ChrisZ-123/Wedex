# Wedex

用你自己的官方 Codex 账号，在微信里和私人 AI 助手聊天。支持上下文、角色、版本化记忆、原生联网、看图、生图和改图，并提供本机网页控制台。

[English](README.en.md) · [安装与使用](docs/USAGE.md) · [验证记录](docs/VALIDATION.md) · [来源与许可](docs/PROVENANCE.md)

**v0.1.0 是 Windows x64 预览版。** 只接收扫码绑定主人的私聊，不接入其他联系人、群聊、QQ、鸣潮或账号托管。模型与原生工具取决于你的账号权限、额度、网络及通道能力。项目独立维护，与 OpenAI、腾讯没有隶属关系。

## 三步开始

1. 在 [Releases](https://github.com/ChrisZ-123/Wedex/releases) 下载 `Wedex-v0.1.0-windows-x64.zip`，解压到你准备长期保留的目录。不要直接在压缩包里运行。
2. 双击 `Wedex.bat`。可见的 PowerShell 启动页提供「安装/检查」「启动助手」「打开控制台」「检查状态」「停止助手」五个操作。首次会自动准备本项目专用运行环境，完成后启动后台并打开控制台。
3. 在控制台完成 **Codex 官方登录**，再用自己的微信扫描 **官方 ClawBot 二维码**，按手机提示确认；两端就绪后给助手发私聊。

无需预装 Node.js、npm 或 Git；默认无需管理员权限。安装会联网下载官方固定版本 **Node.js 24.22.0**、**Codex 0.163.0**，并按锁文件安装依赖。运行环境、登录和数据保留在解压目录内；不修改机器或用户的全局 PATH。

启动页使用当前用户的按需计划任务维持独立后台，默认不开机或登录自启。关闭启动页、浏览器或 Codex 桌面软件后后台仍可运行；请用「停止助手」主动停止。注销、关机、睡眠或断网会影响服务。

控制台固定为 `127.0.0.1:3130`，通过启动器打开以完成本机鉴权。一个端口只允许一个实例；端口被占用时会明确失败。启动器不会接管或停止已有 Webot 或其他程序。

## 能做什么

| 能力 | 使用方法与边界 |
| --- | --- |
| 连续聊天与模型 | 维护上下文；模型、推理强度与服务档位来自当前账号动态目录，不硬编码可用模型、不自动换模型。 |
| 角色与记忆 | 导入或粘贴角色文字；明确说「记住……」提出记忆操作，控制台可管理、置顶和查看版本。 |
| 表达反馈 | 对已完成回复标记「合适 / 太长 / 多余」并可撤销，从后续回复生效。 |
| 联网与看图 | 由 Codex 原生工具联网和理解图片；文字与图片分开发送时按实际到达顺序处理。 |
| 生图与改图 | 明确说出创作或修改要求；控制台可查看进度、耗时与缩略图。工具不可用或失败会显示原因，不自动换模型或再生成。 |
| 微信引用 | 只在来信实际提供引用字段时还原精确引用。没有字段时，明确说明「修改上一张生成图」等上下文目标。 |
| 语音 | 只使用微信通道提供的转写文字；没有转写就提示无法理解，不另调语音识别。 |
| 本地表情 | 默认关闭；显式启用并添加图片与含义后使用，不导入云端收藏。 |
| 历史与备份 | 查看聊天、队列、耗时和发送结果；导出功能数据及可选文字历史，恢复前预览并确认。 |

收取连接中断会显示退避重连状态。模型失败、发送失败或发送结果不明不会自动重新生成或重发；重启也不会重放未完成消息。结果不明时先核对手机，避免重复回复。

## 数据与账号

请亲自完成官方登录、二维码和手机确认。无需 API key；不要复制其他部署、桌面软件或他人的登录文件。账号额度仍按官方账号规则共享。

`state/` 保存聊天、功能数据、媒体与 Windows 当前用户 DPAPI 加密凭据，`codex-home/` 保存独立官方登录及会话，`logs/` 保存运行日志。不要公开整个运行目录。控制台入口含短时鉴权信息，不要分享链接或截图中的鉴权内容。

备份排除微信及控制台凭据、Codex 登录与原生会话、收取游标、普通收图缓存及生成图片文件。换电脑或换 Windows 用户须重新登录和扫码；备份不是完整账号迁移。
